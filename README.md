Parallel Particle Simulation
============================

Fork of the Fracture Effects Programme + Uintah Repository

The main MPM + MPMICE code is called Vaango and can be found in the Vaango directory.

The master has now been updated and partially tested - but only on Ubuntu 24.04 with gcc 13.3.  It uses c++23.  No backward compatibility is maintained.  For older versions of operating systems, use the single release version  from 2022.
